# Subproyectos

La estructura objetivo de Repentista separa los dos productos en carpetas de primer nivel:

- `Game/`: juego móvil y contenido estático publicado.
- `QuatrainGenerator/`: skill, scripts, validadores, puntuador y exportador.

Esta carpeta pertenece al esqueleto inicial de TypeScript y no debe usarse como destino de la arquitectura propuesta. Se conserva mientras se realiza la migración a la estructura documentada.
