## Context

El humor es altamente dependiente de modelo y cultura; se usará como señal editorial, no verdad absoluta.

## Goals / Non-Goals

**Goals:** evidencia, calibración y separación del remate.

**Non-Goals:** garantizar risa o aprobar contenido automáticamente.

## Decisions

- La rúbrica distinguirá sorpresa, absurdo, imagen y juego conceptual, con ejemplos positivos/negativos.
- Se conservará modelo y versión para medir correlación futura con editores.
- El score bajo no será por sí mismo un error operativo ni cambiará reglas duras.

## Risks / Trade-offs

- [Sesgo del juez] → Conjunto diverso de anclas y revisión periódica de distribuciones.
- [Confundir rareza con humor] → Exigir claridad y mecanismo observable.
